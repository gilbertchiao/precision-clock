# Precision Clock 官網

Precision Clock（iPhone 與 Android 毫秒時鐘 App）的公開網站：<https://gilbertchiao.github.io/precision-clock/>

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 首頁（App 介紹） |
| `support.html` | 支援頁（App Store 的 Support URL；Google Play 的網站連結） |
| `privacy.html` | 隱私權政策（App Store 與 Google Play 共用的 Privacy Policy URL） |
| `style.css` | 共用樣式 |

每一頁都同時提供繁體中文與英文。

`favicon.ico` 與 `apple-touch-icon.png` 由 Android 專案的 `docs/play-store/icon-512.png` 縮圖而來
（字型為 Noto Sans，SIL Open Font License；不使用 Apple 的 SF 字型，因其授權不適用於網站）。
